Research

Foundation models for head-and-neck cancer survival prediction

Research assistant, Radiation Oncology, University of Michigan, Mar 2025 – Jan 2026

  • The question: when the dataset is small, do frozen, pretrained CT and PET foundation models help predict recurrence-free survival? We used the public HECKTOR 2022 training split, 524 PET/CT cases from 7 centers.
  • The method: start from a DeepMTS + DAFT baseline, extract fixed embeddings from a CT model (CT-FM) and a PET model (SegAnyPET), pass each through a small linear projection, and concatenate them just before the survival head.
  • The result: under 5-fold cross-validation, mean C-index went from 0.616 to 0.743 and 1-year AUROC from 0.671 to 0.744, with less variation across folds. The folds are small and the ranges overlap, so the paper presents these as preliminary.
  • Published in the Findings Track of the ML4H 2025 Symposium. I'm the first author, with Yiming Liu, Yile Sun, Liyue Shen, and Lise Wei.

MapReduce framework

Python, TCP and UDP sockets, threads

  • A Manager accepts jobs, splits the input files among map tasks, and hands tasks to Workers as JSON messages over TCP.
  • Each map task streams its output into one file per reducer, chosen by hashing the key, and sorts each file. Each reduce task merges its sorted files as a stream, so memory use stays constant.
  • Workers send a heartbeat over UDP every 2 seconds. After 5 missed heartbeats, or a refused connection, the Manager marks the Worker dead and gives its task to another Worker.

Search engine

MapReduce, Flask, SQLite

  • A chain of MapReduce jobs turns a crawl of Wikipedia pages into an inverted index with tf-idf weights and document normalization factors, split into three segments by document ID.
  • Three index servers, each a Flask REST API holding one segment, score documents as a weighted sum of PageRank and tf-idf cosine similarity.
  • The search server sends each query to all three in parallel threads, merges the ranked lists, and looks up titles and summaries in SQLite.

Network file server

C++, Boost threads, TCP sockets

  • A hierarchical file system served over TCP. Clients can create and delete files and directories, and read or write file blocks. Each request runs in its own thread.
  • Every file and directory has a reader/writer lock. A request walks its path with hand-over-hand locking, so requests on unrelated files do not wait for each other.
  • Disk writes are ordered so that a block is written before any block that points to it. A crash at any moment leaves the file system consistent.

Thread library

C++, ucontext

  • A user-level thread library with threads, mutexes, and condition variables, built on ucontext context switches.
  • A timer interrupt can preempt the running thread. The library disables interrupts around its own data structures so that its operations stay atomic.
  • All queues are first in, first out. A thread's stack is freed soon after its function returns, whether or not the thread object still exists.

Virtual memory pager

C++

  • A pager that manages part of each process's address space, with pages backed either by a swap file or by blocks of a regular file.
  • Work is put off for as long as possible. A new swap-backed page points at one shared page of zeros and gets its own physical page only on its first write.
  • When memory is full, the clock algorithm picks a page to evict, and the page is written to disk only if it is dirty.
